# Manter uma mensagem independente por destinatário

O formulário permite selecionar vários contatos, mas cada destinatário terá um registro de mensagem independente. Escolhemos esse modelo para que a ação “Apagar todas as mensagens” de um contato preserve as mensagens dos demais, evitando que um registro compartilhado faça a exclusão afetar outros destinatários. Um envio para vários contatos resulta em vários registros.
